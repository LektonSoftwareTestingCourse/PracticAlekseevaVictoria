# Чек лист
## Smoke-тестирование
Цель: быстрая проверка работоспособности системы после сборки

Запуск системы
- Система успешно запускается через Docker Compose
- Все необходимые сервисы успешно подняты
- Бд и внешние зависимости доступны
- RabbitMQ доступен для обмена сообщениями

Проверка сервисов
- Gateway Service доступен
- Switch Service доступен
- Authorization Service доступен
- Card Management Service доступен
- Terminal Simulator доступен
- Merchant Simulator доступен
- Transaction Logger доступен
- Notification Service доступен
- Web Dashboard доступен

Проверка базовой функциональности
- Создание тестовых карт работает
- Получение данных карты работает
- Выполнение тестовой транзакции работает
- События системы обрабатываются корректно

## Критический путь

Цель: проверка основного сценария прохождения транзакции через процессинговую цепочку

Подготовка операции
- В системе существует тестовая карта
- Терминал может сформировать транзакцию
- Запрос поступает в Gateway Service

Обработка транзакции
- Gateway передает запрос в Switch
- Switch направляет запрос в Authorization Service
- Authorization выполняет проверку карты
- Проверяются статус карты, лимиты и баланс
- При успешной авторизации выполняется резервирование средств

Завершение операции
- Результат авторизации возвращается через процессинговую цепочку
- Transaction Logger сохраняет информацию о транзакции
- Notification Service получает событие
- Web Dashboard отображает результат операции
